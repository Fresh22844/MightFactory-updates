# MightFactory — обновления сборки

Minecraft 1.21.1 · NeoForge 21.1.250

Этот репозиторий используется лаунчером MightFactory для загрузки сборки и её обновлений.

## Игрокам

Скачайте лаунчер из раздела [Releases](https://github.com/Fresh22844/MightFactory-updates/releases). Укажите ник и нажмите «Играть»: необходимые файлы сборки загрузятся автоматически. Пароль вводится уже на игровом сервере через NeoLogin.

Игровой сервер: `95.216.92.69:25797`.

## Администраторам

Каждый выпуск сборки содержит `manifest.json`, файлы модов и `content.zip` с конфигами, квестами и оформлением. Публикуйте весь выпуск целиком. До завершения загрузки используйте черновик релиза. Новая версия появляется у игроков перед следующим запуском или по кнопке «Обновить сборку».

Миры, скриншоты и личные данные игроков не распространяются. Заменяемые файлы сохраняются в резервных копиях. Не публикуйте пароли, ключи и файлы аккаунтов.
